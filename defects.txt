DEFECT 1: Synchronous API Usage in Async Library
--------------------------------------------------------------------------------
Issue: README.md uses blocking synchronous calls
Location: README.md, lines showing "sync.fetch_remote()" and "sync.sync_all()"
Current Code:
    remote_data = sync.fetch_remote()
    sync.sync_all()
    status = sync.verify_integrity()

Expected API (v2.0):
    remote_data = await sync.fetch_remote()
    await sync.sync_all()
    result = await sync.verify_integrity()

Root Cause: DataSyncPro v2.0 migrated from synchronous to asynchronous architecture.
All methods are now async and require await keyword and async context.

Impact: CRITICAL - Code will not execute. TypeError will occur when attempting
        to call async methods without await.
Error Type: RuntimeError - coroutine was never awaited


DEFECT 2: Incorrect Type Handling for verify_integrity()
--------------------------------------------------------------------------------
Issue: Code treats verify_integrity() return value as boolean
Location: README.md, line with "if status:"
Current Code:
    status = sync.verify_integrity()
    if status:
        print("All records verified!")

Actual Return Type (v2.0):
    Returns dictionary with keys:
    - "ok" (bool): Whether all records are verified
    - "missing" (list): Items in remote not in cache
    - "checked" (str): ISO timestamp of verification

Impact: MAJOR - Conditional logic will always evaluate True (non-empty dict).
        The intended behavior of checking individual record status is lost.
Fix: Must check result["ok"] instead of treating entire object as boolean.


DEFECT 3: Missing Async Context
--------------------------------------------------------------------------------
Issue: README example does not show async context management
Current Example Structure:
    sync = DataSyncPro(cache, remote, retries=5)
    remote_data = sync.fetch_remote()  # Missing await and async context

Required Structure (v2.0):
    async def main():
        sync = DataSyncPro(cache, remote, retries=5)
        remote_data = await sync.fetch_remote()
        ...
    asyncio.run(main())

Impact: CRITICAL - Without async context, all async calls will fail.
